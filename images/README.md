# Images

- `cover.jpg` or `cover.png` — the illustration of the house. It appears as the framed
  picture in the header on every page (the .jpg is tried first, then the .png). Until it exists the
  header shows the geometric print instead. A landscape image around 1600 px wide
  works best.
- `plants/` — plant photos, referenced from `plants.js`.
- `projects/` — project photos, referenced from `projects.js`.
